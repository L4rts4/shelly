#Shelly
Seuraavaksi tutkin miten tuon saa siirrettyä iphonelle. Mitä muutoksia vaatii vai toimiiko noin. Sekä yritän lisätä muita ominaisuuksia itse shelly sovelluksesta kuten shelly laitteen salasana vaihto, custom scriptien asennus.
Shellyn käyttö
cd shelly-panel, npm install, npm run dev http://localhost:5173
proxy toimii vain npm run dev tilassa
